McDollibee Digital Kiosk Developed using Java Swing and Visual Studio Code.

Features - Menu Browsing by Category, Food Items with Pictures and Prices, Shopping Cart (Add, Remove, and Clear), Senior Citizen and PWD Discount, Menu Search, Checkout, and Official Receipt Printing

Data Structures and Algorithms Used - ArrayList, 2D Array, Linear Search, and Traversal

OOP Concepts Applied - Encapsulation, Inheritance, Polymorphism, and Abstraction
